# Eventra

Eventra is a lightweight event website built with HTML, CSS, and JavaScript.

## Features
- Event landing page
- Responsive design
- Dynamic content rendering
- Static site deployment ready

## Project Structure
- `index.html` – main page layout
- `styles.css` – styling and responsive design
- `app.js` – page logic and interactions
- `data.js` – sample event data

## Run locally
Open `index.html` in a browser, or serve the folder with a local static server such as:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
